Method References:-   $\rightarrow$ Java provides a new feature called method reference in Java 8.   $\rightarrow$ Method reference is used to refer method of the functional interface. It is a compact and easy form of a Lambda expression.   $\rightarrow$ Each time when you are using a Lambda expression to just referring a method, you can replace your Lambda expression with a method reference.   Types of method References:- (four types):-   1) Method reference to a static method. Its Syntax is Class::StaticMethodName. 2) Reference to an instance method of a particular object. Its Syntax is Object::instanceMethodName. 3) Reference to an instance method of an arbitrary object of specific type. The syntax is Class::instanceMethodName. 4) Reference to a constructor.
