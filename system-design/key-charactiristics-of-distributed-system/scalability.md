## What Scalability Means

- Scalability is the ability of a system to handle a growing workload by adding resources.
- A scalable system keeps working well as users, requests, and data grow.

## A workload can grow in several ways:

- More requests : the number of requests the system receives each second.
- More data : The database grows from 10 GB to 10 TB.
- More users in more places : Users in Chennai and users in London both expect a fast response.
